# May Nigeria Not Happen to You

A single-page article by Sani Yusuf. Everything is in `index.html`.

## Publish on GitHub Pages
1. Create a new repository on GitHub and upload `index.html` and `.nojekyll`.
2. In the repository: Settings, Pages, Source "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The article appears at `https://<your-username>.github.io/<repository-name>/` after a minute or two.

## Read count
Analytics run through GoatCounter, site code `saniyusuf`. To show the public count in the footer,
open GoatCounter, Settings, and tick "Allow adding visitor counts on your website".
